# SRR-002 - 2026-04-29 - T2 Security Review (Post-M9/M10/M11)

**Scope:** Changes since SRR-001 (v0.8.0 -> v0.9.0+)
**Baseline:** 630 tests / 67 files

## Findings Summary

| Severity | Found | Fixed | Remaining |
|----------|-------|-------|-----------|
| HIGH | 2 | 2 | 0 |
| MEDIUM | 3 | 1 | 2 (accepted/deferred) |
| LOW | 2 | 0 | 2 (accepted) |

## HIGH - All Fixed

### S3-10: SSRF via register_probe
**Fix:** Restricted probe URLs to localhost only (127.0.0.1, localhost, ::1).

### S3-11: run_and_watch shell chaining bypass
**Fix:** Added shell metacharacter rejection (`;`, `&`, `|`, `` ` ``, `$`, `()`, `{}`, `!`, `<>`).

## MEDIUM - Fixed

### S5-1: restart_server no rate limiting
**Fix:** Added 5-second cooldown between restarts.

## MEDIUM - Deferred

### S4-1: Probe body may contain secrets
**Accepted:** Probe bodies are stored in memory only, not logged or returned in list_probes. Document limitation.

### Q2-2: 8 untested tool handlers
**Deferred:** Tests needed for register_probe, list_probes, check_port, get_infra_status, get_infra_detail, get_project_health, restart_server, get_requests. Priority for next sprint.

## LOW - Accepted

### Q3-1: Response shape inconsistency (get_server_logs bare array)
**Accepted:** Breaking change deferred to v1.0.0.

### D1-1: No new runtime dependencies
**Info:** All new features use Node.js built-ins only.
