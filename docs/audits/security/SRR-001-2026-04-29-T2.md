## HIGH Findings - All Fixed

### S3-1: Shell injection in run_and_watch
**Risk:** MCP client could execute arbitrary shell commands.
**Fix:** Added command allowlist (npx, npm, node, pytest, tsc, eslint, vitest, jest, go test, cargo test, make, bash). Commands not matching a prefix are rejected with error message.
**File:** `src/tools/run-and-watch.ts`

### Q2-1: 5 untested tool handlers
**Risk:** Security-critical tools (run_and_watch) and composite tools (verify_fix) had zero test coverage.
**Fix:** Added 13 tests covering all 5 handlers: get_health_summary (2), run_and_watch (4), verify_fix (2), wait_for_build (2), wait_for_event (3).
**File:** `tests/unit/tools/audit-missing-tests.test.ts`

## MEDIUM Findings - Fixed

### S3-4: No rate limiting on log collector HTTP server
**Fix:** Added token bucket rate limiter (100 req/s). Returns 429 when exceeded.
**File:** `src/correlation/sources/log-collector.ts`

### S3-6: Missing secret redaction patterns
**Fix:** Added Stripe keys (`sk_live_`, `pk_live_`, `rk_live_`) and npm tokens (`npm_xxxx`).
**File:** `src/constants/redaction.ts`

### S3-7: URL parsing throw in log collector
**Fix:** Wrapped `new URL(url)` in try/catch, returns 400 with "Invalid URL format".
**File:** `src/correlation/sources/log-collector.ts`

## MEDIUM Findings - Accepted Risk

### S3-2: No path traversal protection on log file tailing
**Risk:** Low - path comes from user's own CLI args, not MCP input.
**Mitigation:** Document that `--log-file` should point to project-local files.

### S3-3: No path traversal protection on fingerprint persistence
**Risk:** Low - path is hardcoded constant (`.tracepulse/fingerprints.json`), not user input.
**Mitigation:** None needed - constant is not configurable.

## LOW Findings - Accepted Risk

### S3-5: No auth on log collector HTTP server
**Mitigation:** Binds to 127.0.0.1 only. Local-only access.

### S3-8: Health prober accepts arbitrary URLs
**Mitigation:** URL comes from CLI args (user-controlled), not MCP input.

### S3-9: Theoretical ReDoS in parsers
**Mitigation:** 10KB input guard (`MAX_PARSE_INPUT_LENGTH`) truncates before parsing.

### S8-3: Timer cleanup in blocking tools
**Mitigation:** `timer.unref()` prevents process hang. MCP SDK handles transport close.
